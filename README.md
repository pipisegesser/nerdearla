# Agenda Médica

Sistema web para gestión de turnos médicos que permite a los pacientes consultar, reservar y modificar sus citas médicas.

## Características

- **Consulta de turnos**: Los pacientes pueden ver sus turnos reservados
- **Reserva de nuevos turnos**: Selección de especialidad, doctor, fecha y hora
- **Modificación de turnos**: Cambio de fecha y hora de citas existentes
- **Cancelación de turnos**: Eliminación de citas no deseadas

## Especialidades Disponibles

- Cardiología
- Dermatología
- Traumatología
- Pediatría

## Uso

1. Abrir `index.html` en el navegador
2. Ingresar DNI y apellido para acceder
3. Gestionar turnos desde el panel principal
